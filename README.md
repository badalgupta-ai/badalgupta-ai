# Hi, I'm Badal Gupta

Neuroscience + Computer Science student at **Lake Forest College**.

I'm interested in the space between the lab and the model: turning messy, high-dimensional brain recordings into clear answers about how neural circuits work, and using those answers for brain health.

### Projects

| Project | What it does |
|---|---|
| [**neurofuse**](https://github.com/badalgupta-ai/neurofuse) | A state-space model that fuses calcium imaging and electrophysiology into one shared latent brain state. Laplace-EM with a Kalman smoother, benchmarked on a ground-truth simulator. |
| [**eeg-seizure-detection**](https://github.com/badalgupta-ai/eeg-seizure-detection) | Machine learning on 11,500 EEG segments. Random forest detects seizures with 97.9% accuracy (ROC AUC 0.996). |
